Dedicated administrator access to customer operations.

Davids.Frontend.Admin uses a confidential OAuth 2.1 Authorization Code + PKCE (S256) Backend-for-Frontend flow at Davids.APIGateway backed by the isolated Davids.Services.AdminIdentity OIDC provider.

Isolated RS256 OIDC authority Administrator accounts live in adminidentitydb and sign tokens with dedicated RSA keys published via JWKS discovery.
Zero frontend credential or token exposure Passwords are entered only on the Admin Identity OIDC provider, and tokens stay sealed inside an encrypted HttpOnly Gateway BFF cookie.
